GPT Token Counter: Estimate Tokens for GPT-3.5 and GPT-4

GPT-3.5 and GPT-4 use OpenAI's tiktoken tokenizer. For normal English, it's about 4 characters per token. This tool uses a 0.25 ratio. If you're counting tokens for GPT-4o, same ballpark.

Use this as a quick estimate before you send a huge prompt. It won't match the API to the exact token, but it's close enough to catch surprises. If you're building a chatbot, a RAG pipeline, or a batch job, knowing your token count early saves money.

Claude Token Counter: Tokens for Anthropic Models

Claude 3 from Anthropic uses a different tokenizer. It tends to split text a bit more, so we use a 0.28 ratio. That means 1 token ≈ 3.6 characters.

Llama Token Counter: Meta's Models

Llama 2 and Llama 3 from Meta use their own tokenizer. We use a 0.24 ratio, so 1 token ≈ 4.2 characters. Llama is a bit more efficient on English than GPT in some cases.

Again, estimate only. If you're running Llama locally or through an API, use the count to plan your context window and avoid truncation.

Frequently Asked Questions

What is an LLM token?

A token is the basic unit of text an LLM processes. It can be a character, part of a word, or a whole word. In English, 1 token is roughly 4 characters or 0.75 words.

How many tokens is 1,000 words?

About 1,333 tokens. The common rule is 1 word = 1.33 tokens, or 1 token = 0.75 words. Code and punctuation push this higher.

How many words is 1,000 tokens?

Roughly 750 words for plain English. That number drops if you're counting code, URLs, or JSON.

How do I count tokens for GPT-4?

Use this tool, select GPT-4, and paste your text. It estimates tokens at 0.25 tokens per character, which is close to OpenAI's tiktoken tokenizer for normal English.

How do I count tokens for Claude?

Pick Claude 3 in the model dropdown. Claude tends to split text a bit more, so the tool uses a 0.28 ratio. That gives you a slightly higher count than GPT.

How do I count tokens for Llama?

Select Llama 2 or Llama 3. The tool uses a 0.24 ratio. Llama is a little more efficient on English than GPT in some cases.

Is this LLM token counter free?

Yes. No signup, no watermark, no limit. It's a static page with vanilla JavaScript, so there's no server cost to pass on to you.

Does this tool upload my text?

No. Everything runs in your browser. Your prompt never leaves your machine. Open DevTools and watch the Network tab if you want proof.

Why does the token count differ from OpenAI's tokenizer?

This tool uses a character-to-token ratio, not the exact BPE tokenizer. It's an estimate. For billing, always check your provider's dashboard.

What is the difference between tokens and characters?

A character is a single letter, number, or symbol. A token is what the model actually reads. In English, 1 token is about 4 characters. In code, it can be 1-2 characters per token.

Can I use this token counter for code?

Yes, but expect more tokens per character. Braces, semicolons, and indentation all cost tokens. The estimate will be higher than plain English.

What is the max context window for GPT-4?

GPT-4 has variants with 8K, 32K, and 128K token context windows. GPT-4o supports up to 128K. Always check the current model docs before building.
